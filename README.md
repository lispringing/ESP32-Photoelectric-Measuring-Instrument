# ESP32-Photoelectric-Measuring-Instrument
基于ESP32制作的多功能光电测量仪

## 项目简洁
>本项目基于了ESP32-S3开发板以及一堆模块，实现了低价格(100左右)手搓出一个多功能光电检测仪，开发周期短，可玩性高，大家复刻后可以拿去去前往参赛/用作毕设

## 功能介绍
✅支持光照强弱检测

✅支持光照流明检测

✅支持光照流明检测

## 快速开始

克隆本仓库，用Arduino打开esp32文件夹下的eps32.ino文件，烧录
```
https://github.com/lispringing/ESP32-Photoelectric-Measuring-Instrument
```
> 按照引脚连接模块方式连接好后，wifi连接ESP—Light ，密码12345678,浏览器访问192.168.4.1即可进入后台
## 引脚连接方式
![截图](/img/main.png)

| 模块引脚 | 开发板引脚 |             
| ----- | ----- |
| 红外避障传感器模块3.3V | 开发板3.3V |
| 红外避障传感器模块GND | 开发板GND |
| 红外避障传感器模块DO | 开发板7号脚  |
| 4针光伏传感器模块3.3v | 开发板3.3V |
| 4针光伏传感器模块GND | 开发板GND |
| 4针光伏传感器模块AO | 开发板5号脚 |
| 4针光伏传感器模块DO | 开发板4号脚 |
