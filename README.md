# ESP32-Photoelectric-Measuring-Instrument
基于ESP32制作的多功能光电测量仪

## 项目简洁
>本项目基于了ESP32-S3开发板以及一堆模块，实现了低价格(100左右)手搓出一个多功能光电检测仪，开发周期短，可玩性高，大家复刻后可以拿去去前往参赛/用作毕设
